# Setup and Running Guide

How to install, train, evaluate, and run the web app for the fake job detection system.

---

## Installation

```bash
git clone <repo-url>
cd fake_jobs
pip install -r requirements.txt
git lfs pull          # download model artifacts (.pt, .joblib)
```

**Requirements:** Python 3.10+. Full list in `requirements.txt`.

---

## Datasets

Place these two files in `data/raw/` before running anything:

| File | Source |
|---|---|
| `fake_job_postings.csv` | EMSCAD — [Kaggle](https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction) |
| `Fake_Postings.csv` | OpenBay — [Kaggle](https://www.kaggle.com/datasets/rabieelkharoua/predict-online-job-fraud-dataset) |

---

## Full Training Pipeline (run in this order)

```bash
# 1. Clean data, merge 8 job fields, create splits.json (seed=42, 60/20/20)
python -m src.prep

# 2. Train baseline models
python -m src.train_classical_models    # LogReg, NB, RF, XGBoost, LightGBM
python -m src.train_bilstm              # Bi-LSTM
python -m src.train_distilbert          # DistilBERT fine-tuning
python -m src.train_textgcn_enhanced    # 3-layer TextGCN (baseline)

# 3. Aggregate baseline metrics into one comparison CSV
python -m src.compare_models

# 4. Train tuned models
python -m tuned_models.tune_classical_models
python -m tuned_models.tune_bilstm
python -m tuned_models.tune_distilbert
python tuned_models/best_tuned_textgcn_model.py   # Production TextGCN (3-seed ensemble)
```

Classical models + Bi-LSTM train in minutes. DistilBERT takes ~25 min. TextGCN ensemble takes ~13 min per seed (3 seeds = ~40 min total).

---

## Evaluation

```bash
# Quick stats — reads all metrics CSVs, no retraining needed
python evaluate_only.py

# Regenerate comparison charts (bar charts + heatmap → reports/figures/)
python -m src.plot_model_comparison

# Before/after tuning chart
python -m src.plot_before_after_tuning
```

---

## Analysis Scripts

These produce the dissertation evidence. All outputs written to `reports/`.

```bash
# Dataset class distribution and text length statistics
python -m src.analysis.dataset_statistics
# → reports/dataset_statistics.csv

# 6-variant ablation study (layer depth, residual, PMI, window size)
python -m src.analysis.ablation_study
# → reports/ablation_results.csv

# 3-fold cross-validation (TextGCN vs LightGBM)
python -m src.analysis.cross_validation_report
# → reports/cross_validation_results.csv, reports/cross_validation_summary.txt

# Error analysis — characterise false positives and false negatives
python -m src.analysis.error_analysis
# → reports/error_analysis_fp.csv, reports/error_analysis_fn.csv, reports/error_analysis_summary.txt

# SHAP faithfulness test — verify explanations reflect real model decisions
python -m src.analysis.faithfulness_test
# → reports/faithfulness_results.csv, reports/faithfulness_summary.txt

# Advanced TextGCN tuning (5 experiments trying to beat F1=0.8390)
python tuned_models/textgcn_advanced_tuning.py
# → reports/tuned/advanced_tuning_results.csv
```

## Web App

```bash
streamlit run web_app/app.py
```

Opens at `http://localhost:8501`.

**Required model artifacts** (in `models/tuned/textgcn_tuned/`):
- `textgcn_tuned.pt`
- `graph_cache_tuned.pt`
- `vectorizer_tuned.joblib`

Generate them by running `python tuned_models/best_tuned_textgcn_model.py` if missing.

**Pages:**
| Page | Description |
|---|---|
| Detector | Paste a job posting → get fraud probability + token-level highlights |
| Explainability | SHAP attribution, occlusion audit, highlighted text, reliability score |
