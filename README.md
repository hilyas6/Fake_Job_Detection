# Fake Job Posting Detection

A multi-model system for detecting fraudulent job postings, trained on the EMSCAD dataset and evaluated on OpenBay as an out-of-distribution benchmark. Includes a Streamlit web app with SHAP-based explainability powered by a tuned TextGCN ensemble.

## Reproducing from Scratch

### 1. Clone and install

```bash
git clone <repo-url>
cd fake_jobs
pip install -r requirements.txt
```

### 2. Download the datasets

Place these two files into `data/raw/`:

| File | Source |
|---|---|
| `fake_job_postings.csv` | [EMSCAD on Kaggle](https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction) |
| `Fake_Postings.csv` | [OpenBay dataset](https://www.kaggle.com/datasets/rabieelkharoua/predict-online-job-fraud-dataset) |

### 3. Prepare the data

```bash
python -m src.prep
```

This cleans the raw CSVs, normalises text (emails → `__EMAIL__`, URLs → `__URL__`, etc.), merges 8 job fields with `[SEP]` tokens, deduplicates, and writes `data/processed/emscad.csv`, `data/processed/openbay.csv`, and `data/processed/splits.json`.

## Training - Baseline Models

Train each baseline model independently. All scripts write metrics to `reports/`.

```bash
# Classical models (LogReg, Naive Bayes, Random Forest, XGBoost, LightGBM)
python -m src.train_classical_models

# Bi-LSTM
python -m src.train_bilstm

# DistilBERT
python -m src.train_distilbert

# TextGCN (3-layer with residual connections - baseline)
python -m src.train_textgcn_enhanced
```

---

## Training - Tuned Models

Each tuning script is independent. Run them after their corresponding baseline.

```bash
# Tuned classical models
python -m tuned_models.tune_classical_models

# Tuned Bi-LSTM
python -m tuned_models.tune_bilstm

# Tuned DistilBERT (4 epochs, class weighting, linear warmup)
python -m tuned_models.tune_distilbert

# Tuned TextGCN - winning configuration (3-seed ensemble, PMI window=15)
python -m tuned_models.best_tuned_textgcn_model
```

> **Note:** `tuned_models/tune_textgcn.py` contains the full 34-trial exploration search used to find the winning configuration. It is kept for reference but does not need to be run. Use `best_tuned_textgcn_model.py` to reproduce the production model directly.

### Recommended training order

```
src.prep
  → src.train_classical_models    → tuned_models.tune_classical_models
  → src.train_bilstm              → tuned_models.tune_bilstm
  → src.train_distilbert          → tuned_models.tune_distilbert
  → src.train_textgcn_enhanced    → tuned_models.best_tuned_textgcn_model
```

Classical models and Bi-LSTM train in minutes. DistilBERT takes ~25 minutes per trial (3 trials). The TextGCN ensemble takes ~13 minutes per seed (3 seeds).

## Evaluation

### Quick stats (no retraining)

```bash
python evaluate_only.py
```

Reads all saved metrics CSVs and prints a ranked table of every model (baseline and tuned) with F1, Precision, Recall, OOD Recall, and Threshold.

### Regenerate the comparison CSV and figures

```bash

python -m src.compare_models

# Generate bar charts and heatmap (reports/figures/)
python -m src.plot_model_comparison

# Generate before/after tuning chart
python -m src.plot_before_after_tuning
```

## Web Application

The web app uses the **tuned TextGCN ensemble** from `models/tuned/textgcn_tuned/`.

### Required artifacts

```
models/tuned/textgcn_tuned/textgcn_tuned.pt
models/tuned/textgcn_tuned/graph_cache_tuned.pt
models/tuned/textgcn_tuned/vectorizer_tuned.joblib
```

Generate them by running `python -m tuned_models.best_tuned_textgcn_model`.

### Run

```bash
streamlit run web_app/app.py
```

Opens at `http://localhost:8501`.

### Pages

| Page | Description |
|---|---|
| **Detector** | Paste a job posting and get a fraud probability with token-level signals |
| **Explainability** | Full report: SHAP attribution charts, occlusion audit, highlighted text, model methodology |

## Model Results Summary

| Model | Version | Test F1 | Precision | Recall | OOD Recall |
|---|---|---|---|---|---|
| TextGCN (Tuned Ensemble) | **Tuned** | **0.839** | **0.903** | 0.783 | 0.933 |
| TextGCN (Improved) | Baseline | 0.835 | 0.877 | 0.797 | 0.958 |
| LightGBM | Tuned | 0.849 | 0.948 | 0.769 | 0.991 |
| LightGBM | Baseline | 0.834 | 0.883 | 0.790 | 1.000 |
| DistilBERT | Tuned | 0.823 | 0.801 | 0.846 | 0.404 |
| XGBoost | Tuned | 0.804 | 0.804 | 0.804 | 0.999 |
| BiLSTM | Tuned | 0.774 | 0.809 | 0.741 | 0.370 |

Full results and all 34 TextGCN trial records are in `reports/MODEL_TUNING.md`.

> **Why TextGCN for the web app?** LightGBM achieves slightly higher raw F1 (0.849 vs 0.839), but TextGCN is chosen for production because it supports token-level SHAP attribution, uncertainty estimation via MC Dropout, and graph-based co-occurrence representations that generalise better across datasets.

## Dataset Notes

- **EMSCAD** - ~17,880 real + ~800 fraudulent job postings. Split 60/20/20 (train/val/test), stratified, seed = 42. Defined in `data/processed/splits.json` for reproducibility across all scripts.
- **OpenBay** - Used only for out-of-distribution evaluation. Never seen during training.
- `data/raw/` is excluded from git (large files). `data/processed/` is also excluded and regenerated by `src.prep`.
